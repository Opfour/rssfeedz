# Feed Court

I dearly loved the wall of text aggregator [Popurls](http://web.archive.org/web/20151031011257/http://popurls.com/), until they started messing with it, forcing in images and dropping customization. It didn't seem to hard to create a clone of my own, so that's what this project is: a dead simple server-side web app that grabs RSS feeds and puts them on a page. 

The index.html is generated by a cron'd python script that reads a list of rss feeds. Vanilla javascript creates an event to expand div to see more text. That's about it for now. 

## Live mode (reload pulls fresh data)

`server.py` runs as a systemd user unit and serves the page, refetching every
feed in `feedlist.txt` on demand:

```bash
systemctl --user status rssfeedz     # is it up?
systemctl --user restart rssfeedz    # after editing server.py
journalctl --user -u rssfeedz -f     # per-feed failures
```

Browse http://localhost:8111/

- the feed cache lives 4 hours, so ordinary reloads are instant
- a browser hard reload (Ctrl+Shift+R, or Shift+click reload) bypasses the cache
  and refetches, the server detects the no-cache request and tells the page
- the green `refresh` link (or `/api/feeds?fresh=1`) forces a refetch too
- `?view=jumble` gives the randomized single-column view
- last good copy of every feed is stored in `feedcache.json`, so a slow or dead
  feed keeps its previous headlines instead of vanishing
- Reddit allows roughly one anonymous .rss request per window per IP, so at most
  two Reddit feeds refresh per rebuild and the rest keep their cached copy
- opening `index.html` from disk (`file://`) cannot fetch feeds; browsers block
  cross-site reads. It shows a reminder to open the localhost URL instead.

`parsefeeds.py` still writes a static snapshot (`static.html` plus `jumble.html`)
on a 4 hour cron, which is a useful offline fallback but is no longer the page
you browse.

## Included OMPL2TXT converter
1) Download the OPML files you want from the repo: https://github.com/plenaryapp/awesome-rss-feeds
   
### Convert a single OPML file
2) Run the opml2txt.py file
   
```python3 opml_to_feedlist.py recommended.opml```

### Convert multiple OPML files into one feedlist
3) Convert files
   
```python3 opml_to_feedlist.py tech.opml news.opml linux.opml my_feeds.txt```

### Convert all OPML files in a directory
  
```python3 opml_to_feedlist.py *.opml combined_feeds.txt```

4) Copy to rssfeedz:   

```
cp feedlist.txt ~/rssfeedz/feedlist.txt
cd ~/rssfeedz
python3 parsefeeds.py
```

The script automatically:

✓ Removes duplicate feeds

✓ Adds helpful comments with feed titles

✓ Organizes by source file

✓ Handles multiple files at once
