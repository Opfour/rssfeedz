# rssfeedz -- Feed Court RSS Aggregator

Popurls-style wall of text RSS aggregator with an Upstract-style dark grid. Two
front ends over one feed list: `server.py`, the live server on
http://localhost:8111/, and `parsefeeds.py`, which writes static snapshots. The
live server is the one in daily use; the snapshots remain as an offline fallback.

## Commands

```bash
systemctl --user status rssfeedz    # live server on http://localhost:8111/
systemctl --user restart rssfeedz   # after editing server.py or index.html
journalctl --user -u rssfeedz -f    # per feed failures
python3 parsefeeds.py               # regenerate static.html and jumble.html
./update_feeds.sh                   # same, appending output to update.log
curl -s localhost:8111/api/feeds    # JSON payload the page renders
```

Cron entry (user crontab): `0 */4 * * * /home/david/rssfeedz/update_feeds.sh`.
`feed.refresh.sh` is byte identical to `update_feeds.sh`. `example.cron` is
stale: it points at the old `~/feedcourt` path and a venv python, and nothing
runs it.

## Key Files

- `server.py` -- Live server: fetches `feedlist.txt`, extracts images and video
  flags, serves `index.html`, `feedcourt.css` and `/api/feeds`. 4 hour cache,
  `?fresh=1` or a hard reload bypasses it
- `index.html` -- The whole live front end: wires, card grid, ticker, media
  strips are rendered inline here, not in `feedcourt.js`
- `feedcourt.css` -- Live styling: palette variables and base font size at the
  top, then wall, wire and video row rules
- `feedcourt.js` -- Static snapshots only: expands and collapses the "more"
  sections and rewrites the UTC stamp to local time
- `parsefeeds.py` -- Static snapshot generator, writes `static.html` and
  `jumble.html` with a 600s meta refresh
- `feedlist.txt` -- RSS feed URLs (one per line, `#` comments allowed)
- `feedlist.txt.bak` -- Previous feed list, kept by hand
- `opml2txt.py` -- Converts an OPML export into `feedlist.txt` lines
- `feedcache.json` -- Last good copy of each feed plus its schema version,
  written by `server.py`
- `static.html`, `jumble.html` -- Generated snapshots (grid and shuffled single
  column), offline fallback
- `backups/` -- Pre-rewrite copies of the generated `index.html` and `jumble.html`
- `update.log` -- Cron output from `update_feeds.sh`
- `cron_setup_instructions.txt` -- Notes for installing the cron entry
- `README.md` -- Public-facing project description
- `~/.config/systemd/user/rssfeedz.service` -- Unit that keeps the server
  running at login (linger enabled)

## Output

- Live page: 4 hour cache; a hard reload (Ctrl+Shift+R), `?fresh=1`, or the
  refresh link refetches every feed
- `?view=jumble` renders the same feeds as one shuffled single column instead of
  the grid
- Static snapshot: meta refresh every 600s, regenerated by cron every 4 hours
- "more" on a card reveals the remaining headlines in that card
- Section headings show the source title plus its short domain, e.g.
  `Deeplinks (eff.org)`, and the wire cards show timestamps per headline

## Feed list rules

- one feed per source: `server.py` and `parsefeeds.py` dedupe on registrable
  domain, except reddit (per subreddit), youtube (per channel) and feedburner
  (per feed path)
- `site_domain()` strips scheme, `www`, and subdomains for headings

## Layout rules (index.html)

- text only by default: `IMAGE_OK` is an allow list, not a deny list. Only
  image-first and video-first sources (YouTube, Vimeo, photo feeds) render
  art; every news, tech, magazine and subreddit card carries no image and no
  row thumbnails
- video cards render on full rows of three, freshest first, and are capped to
  a multiple of three (`renderGrid`, `.rowbreak` forces the row break). Keep
  YouTube feeds in multiples of three: surplus feeds are held back rather
  than leaving a partial row, and a card row never mixes video with text
- YouTube Atom feeds return intermittent 404/500, so `fetch_bytes` retries
  `youtube.com/feeds` three times with backoff; expect channel gaps without it
- typography for readability: 17.5px body, near-white ink, secondary text
  never below `--dim`; colors and base size are the variables and `font:` line
  at the top of `feedcourt.css`

## Workflow

1. Edit feeds: modify `feedlist.txt`
2. Restart the service if you changed code, reload the page for new feeds
3. Static: `python3 parsefeeds.py`, open `static.html`
4. Automate: `update_feeds.sh` in crontab (every 4 hours, already installed)
