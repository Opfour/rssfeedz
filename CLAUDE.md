# rssfeedz -- Feed Court RSS Aggregator

Static HTML RSS aggregator that generates a wall-of-text view of RSS feeds. This is the only home-directory project with git version control.

## Commands

```bash
./server.py              # Live page on http://localhost:8111/ (reload = fresh)
python3 parsefeeds.py    # Static snapshot for cron (static.html, jumble.html)
./feed.refresh.sh        # Refresh static snapshot (used by cron)
```

## Key Files

- `server.py` -- Live server: fetches feedlist.txt per request, serves index.html + /api/feeds
- `parsefeeds.py` -- Static snapshot generator, writes static.html and jumble.html
- `feedlist.txt` -- RSS feed URLs (one per line)
- `index.html` -- Hand-written live page; renders /api/feeds client-side
- `static.html` -- Generated snapshot (cron), offline fallback
- `jumble.html` -- Generated randomized snapshot
- `feedcache.json` -- Last good copy of each feed, written by server.py
- `feedcourt.css` -- Styling
- `feedcourt.js` -- Client-side interactions
- `backups/` -- Dated copies of the pre-live index.html
- `example.cron` -- Example cron configuration

## Output

- Live page: fetched per request, 60s cache, `refresh` link forces a rebuild
- Static snapshot: auto-refresh meta tag (600s), regenerated by cron
- "More" expansion for each feed section
- Sorted and jumbled views (`/?view=jumble` for jumble)

## Workflow

1. Edit feeds: modify `feedlist.txt`
2. Live: `./server.py`, browse http://localhost:8111/
3. Static: `python3 parsefeeds.py`, open `static.html`
4. Automate: `feed.refresh.sh` in crontab (every 2 hours)
